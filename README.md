# E-Commerce-Sales-Profit-Interactive-Data-Story
This project is an interactive E-Commerce Sales and Profit Data Story created using Tableau. It analyzes sales, profit, orders, products, regions, customer segments, and shipping performance. The dashboards present the analysis in a clear story, starting with overall business performance and moving toward trends, category performance, regional analysis, customer and shipping insights, and profitability. The project also includes an interactive business explorer where users can filter data by year, category, and customer segment. A metric parameter allows users to switch between Sales, Profit, and Quantity. Dashboard actions and interactive filters help users explore the data and identify useful business insights.

The story starts with the overall business performance, then moves to trends over time, category performance and finally an interactive business explorer. The dashboards help answer questions such as:

How are sales and profit changing over time?

Which categories and sub-categories perform best?

Which regions contribute more to the business?

Are high-sales areas also generating good profit?

How can a user explore the data for a particular year, category or customer segment?

Main Story

E-Commerce Sales & Profit Performance

The story follows this flow:

Interactive Metric Parameter

The final interactive dashboard uses a parameter called Select metric.

It allows the user to switch between:

Sales

Profit

Quantity

The parameter is connected to a calculated field called Selected Metric:

CASE [Select Metric]

WHEN "Sales" THEN SUM([Sales])

WHEN "Profit" THEN SUM([Profit])

WHEN "Quantity" THEN SUM([Quantity])

END

This allows the same visualization to answer different business questions without creating a separate chart for every metric.

Filters

The interactive dashboard is designed around these filters:

Order Year – 2023, 2024 and 2025

Category – Furniture, Office Supplies and Technology

Segment – Consumer, Corporate and Home Office

The filters allow users to narrow the story and investigate a specific part of the business.

Dashboard Actions

Dashboard actions make the story interactive.

A category selection can be used as a filter action so that selecting a category updates the other relevant views. Highlight actions can also help users visually connect related marks across charts.

These actions make it easier to move from a general comparison to a more focused analysis.

Key Visualizations

Monthly Sales & Profit Trend

Shows how sales and profit change month by month. It helps identify growth periods, slow periods and changes in business performance.

Yearly Sales Performance

Compares sales across the available years and gives a quick view of yearly growth.

Yearly Profit Performance

Compares yearly profit and helps the user see whether sales growth is also producing better profit.

Monthly Orders Trend

Shows changes in order volume over time and provides context for the sales trend.

Sales by Category

Compares sales generated by the main product categories.

Profit by Category

Shows which categories contribute more to profit, which can be different from the sales ranking.

Sales and Profit by Sub-Category

Provides a more detailed view and helps identify strong and weak product groups.

Regional Performance

Compares sales and profit across regions and states to identify geographic differences.

Sales vs Profit

The scatter plot compares sales and profit. It helps identify areas with high sales and high profit, as well as areas where sales are high but profit is relatively weak.

Selected Metric by Category

This is an interactive chart controlled by the metric parameter. The user can switch between Sales, Profit and Quantity.

Selected Metric by Region

This provides the same metric-switching experience at the regional level.

Conclusion

This project turns an e-commerce dataset into an interactive Tableau data story. Instead of presenting unrelated charts, the dashboards follow a logical sequence from overall performance to detailed analysis and finally user-driven exploration.

The interactive filters, metric parameter and dashboard actions allow users to move from a high-level view to a specific business question and explore the data based on their own requirements.
